## Clean-room rule

Do not copy patterns or rule text from Semgrep rules (Semgrep Rules License), TruffleHog (AGPL),
or any GPL or LGPL source. Derive patterns from provider documentation and public formats and
record the documentation URL for every regex family in `docs/guard/sources/*.md`. Model-written
patterns can coincide with gitleaks or detect-secrets patterns, so `cli/tests/guard/support/similarity.py`
compares token families with any locally available gitleaks and detect-secrets rule files (it
skips silently when none exist). The contract does not claim that no third-party text was copied:
only that this was done best effort and documented.

## Text Guard writes into users' repositories

The rule-file block, the Cursor and Windsurf rule files, the pre-commit snippet, the `init --ci`
workflow and the plugin skill are released under CC0-1.0 in addition to the repository licence, so a
user's proprietary repository does not embed AGPL-covered text. Each template's source header
comment says so.
